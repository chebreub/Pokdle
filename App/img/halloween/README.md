# Halloween decorations

Pokémon artwork: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork
24 visitors: 92, 93, 94, 198, 200, 302, 353, 354, 355, 425, 429, 430, 442, 477, 479, 562, 570, 607, 609, 708, 709, 710, 778, 855.
The initial eight images are 192 px transparent WebP; the additional sixteen retain the original transparent PNG.
Images are local and loaded one at a time when a visit begins, not all at startup.
Pokémon © Nintendo / Creatures Inc. / GAME FREAK inc.; existing site attribution applies.
The hat and corner webs are original inline SVG.

The costume is active October 15 through November 1, using the Paris calendar.
The logo costume and seasonal frame follow every page. Visitors are independent of game answers.
The first arrival is scheduled after 1.6 seconds; subsequent quiet intervals are 4.5–9 seconds on desktop,
7–11.5 seconds on mobile, in addition to each 8.2–9.5 second appearance.
A shuffled bag shows all 24 species before repeating. There is only one visitor at a time.
Artwork is placed in free space around visible controls and text. Full crossings only use an empty strip on browsing pages.
Dense screens may skip a visit when no safe area fits. Navigation, scrolling, dialogs, typing, hidden tabs and
reduced motion cancel the current visit. Recalculation prevents an old flight from crossing a new game screen.
The display preference is Settings → Affichage → Décorations de saison.
