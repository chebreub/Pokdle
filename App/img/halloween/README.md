# Halloween decorations

Pokémon artwork: PokeAPI sprites repository, `sprites/pokemon/other/official-artwork/{id}.png`.
Source: https://github.com/PokeAPI/sprites
Local versions resized to 192 px and encoded as transparent WebP with Sharp (quality 82).
IDs: 92, 93, 94, 198, 425, 607, 710, 778.
Pokémon © Nintendo / Creatures Inc. / GAME FREAK inc.; existing site attribution applies.
Hat and corner webs are original inline SVG decorations in `script.13.halloween.js`.

The costume is active from October 15 through November 1, using the Paris calendar.
Visitors are independent of game answers and only appear on home/catalog/rankings.
Only one visitor at a time; dialogs, typing, hidden tabs and reduced motion stop visits.
The display preference is under Settings → Affichage → Décorations de saison.
