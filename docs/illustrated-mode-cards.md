# Illustrations des modes — pilote du 6 octobre 2026

Trois illustrations originales ont été générées avec l’outil intégré ImageGen, puis exportées en WebP avec Sharp (qualité 82, largeurs 480 et 960 px). Les originaux générés sont conservés séparément ; le site utilise uniquement les six fichiers optimisés ci-dessous.

| Mode | Fichiers dans App/img/modes | Scène |
| --- | --- | --- |
| Pokémon du jour | daily-v1-480.webp ; daily-v1-960.webp | Enquête dans une clairière, sans rapport avec la cible réelle du Daily |
| Poké-Connections | connections-v1-480.webp ; connections-v1-960.webp | Évoli, Mentali, Noctali et Nymphali autour de pièces de puzzle |
| Draft Score Attack | draft-v1-480.webp ; draft-v1-960.webp | Gardevoir, Lucario et Corvaillus devant une arène |

Les images sont décoratives (`alt=""`, parent `aria-hidden`) ; les titres, descriptions et commandes restent en HTML. Les variantes ont des noms versionnés pour respecter le cache des images. Aucun changement aux règles, aux récompenses ni aux sauvegardes.

Le catalogue solo met en avant ces trois modes. Mode illimité reste le premier jeu de la rubrique Deviner. Les recherches et les filtres retrouvent les cartes illustrées dans les rubriques normales, y compris la variante Draft PRO. La sélection multijoueur conserve ses modes habituels.

Sur ordinateur, chaque scène occupe la largeur de sa carte, au-dessus du texte. Sur téléphone, la scène conserve son ratio 3:2 à côté du texte, pour laisser davantage de jeux visibles. Aucun effet animé n’est nécessaire pour comprendre ou utiliser les cartes.
